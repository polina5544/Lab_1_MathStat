## Что включено

| Файл | Назначение |
|---|---|
| `KTvD_Wine_Research.ipynb` | **Основной сдаваемый файл** — воспроизводимое Jupyter-исследование (178 наблюдений, X и Y, EDA, дескриптивная статистика, стандартизация, Пирсон/Спирмен, 10 000 перестановок, bootstrap, устойчивость оценки); все ячейки выполнены с сохранёнными результатами |
| `KTvD_Wine_Research.html` | Оформленная версия исследования в утверждённом дизайне Spectral Nightfall: навигация, свёрнутый Python-код, графики и выводы. Без таблицы критериев |
| `KTvD_Interactive.html` | **Рабочая автономная интерактивная демонстрация** на том же Wine-наборе; выбор n, перемешивание Y, фиксируемое зерно, графики и перестановочный p-value. Открывается локально в браузере |
| `KTvD_Wine_marimo.py` | Финальная интерактивная реализация для marimo с исправленным выпадающим списком; предыдущую версию пользователь успешно запустил, новый дизайн пока ожидает повторной проверки в marimo 0.25.2 |
| `spectral_nightfall.css` | Файл темы для marimo — должен лежать рядом с `KTvD_Wine_marimo.py` |
| `data/wine_two_variables.csv` | Локальная копия данных для воспроизводимости, не требует подключения к интернету |
| `requirements.txt` | Зависимости для запуска `.ipynb` и marimo |

## Как сохранить и загрузить в GitHub

1. Распаковать ZIP **с сохранением структуры папок**.
2. Внутри командного репозитория лучше создать отдельную папку `KTvD/` и загрузить в неё файлы из этого архива вместе с подкаталогом `data/`. В идеале сначала согласовать это с командой, не делать force push в `main`.
3. Если преподаватель подтвердит индивидуальную сдачу — загрузить комплект в собственный или учебный репозиторий, согласно его правилам.
4. Для предварительного просмотра открыть `KTvD_Wine_Research.html` и `KTvD_Interactive.html` в браузере. GitHub по умолчанию **не отображает HTML как сайт**; для просмотра в браузере удобнее скачать HTML, либо включить GitHub Pages по правилам репозитория.
5. Скопировать ссылку на нужный GitHub-репозиторий и полный hash коммита, после чего заполнить форму преподавателя. В форме выбрать соответствующий этап; не помечать работу как окончательно интегрированную с командным генератором, пока этого нет.

## Локальный запуск

В корне распакованной папки:

```bash
python -m pip install -r requirements.txt
jupyter notebook KTvD_Wine_Research.ipynb
```

Дополнительная marimo-версия:

```bash
python -m marimo run KTvD_Wine_marimo.py
```

HTML-файлам Python не требуется.

## Подтверждённые результаты и границы утверждений

- Проверена структура CSV: 178 полных пар `alcohol` × `color_intensity`.
- Исследовательский `.ipynb` выполнен через Jupyter-kernel без ошибок, с фиксированными генераторами.
- Для всей выборки коэффициент Пирсона около **0,546**. Перестановочный тест даёт p менее 0,05.
- JS-код интерактивной страницы проверен: переключение парности, выбор n, обновление p и зерна выполняются; синтаксис JavaScript корректен.
- **Предыдущая версия marimo** успешно запускалась на компьютере пользователя после исправления dropdown. Новый интерфейс Spectral Nightfall проходит проверку Python-синтаксиса, но его ещё требуется открыть локально и проверить работу интерактивных элементов.
- Этот комплект не закрывает критерии, относящиеся к **общему командному Jupyter** (основной Raman-ноутбук, финальное оформление его графиков, его `cat_mark_table`, интерфейс именно командного генератора). Для них нужна последняя версия работы команды.

## Источник данных

Wine Recognition / UCI Machine Learning Repository, стандартный набор данных `sklearn.datasets.load_wine`. В CSV взяты два количественных признака каждого образца; целевая категория вина не используется. Это наблюдательные данные, выводы о причинности не делаются.
